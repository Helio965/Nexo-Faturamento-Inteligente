# Documentos Obsoletos

Esta pasta contém documentos de versões anteriores ao DER V4.1 que **não devem ser usados como referência ativa**.

## Por que são obsoletos?

- Citam 8 ou 12 tabelas (o MVP V4.1 tem exatamente 10)
- Incluem Power BI Embedded (descartado)
- Usam nomes de plano antigos: Nexo Start, Nexo Performance, Fatura Plus
- Citam fórmula errada: `total_comprado - faturamento_total`
- Tratam a Central de Tickets como fora do MVP (está dentro desde V4.1)
- Incluem tabelas fora do MVP como ativas: `avaliacao_analise`, `fatura_cobranca`, etc.
